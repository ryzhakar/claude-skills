# agent-conduct

Domain-free skills governing how an agent conducts itself while working, independent of orchestration, memory, or any specific engineering domain.

`conduct` `behavior` `output-discipline` `silence` 
## Skills

### [check-back](skills/check-back/SKILL.md)

Before ending a turn that leaves a run pending, set the agent's own next wake, and on waking look at what was pending. "check back", "check back in 10 minutes", "wake up when it's done", "keep an eye on the build", "wait for the agents", "don't lose track of background work", "pick up after a resume", or any turn about to end while a background command, a background agent, or an external wait is still running.


---

### [peer-protocol](skills/peer-protocol/SKILL.md)

Coordinate this main session with the other Claude Code sessions on this machine through the shared registry, a card per session, and tagged messages. "join the peers", "peer protocol", "message a sibling session", "message a peer session", "tell the other session", "propose a protocol change", "change the peer protocol", a circulated protocol draft, a dispute between sessions, "share a lesson with the peers", "add to the commons", a lesson, tip, trick, or tool worth passing on, a SessionStart peer-join notice, or any cross-session message that arrives, such as one opening with `[hazard]`, `[ask]`, `[answer]`, or `[notice]`.


---

### [work-silently](skills/work-silently/SKILL.md)

Keep working while writing nothing to the conversation, except answers to the user's own messages, until the user says to stop. "/work-silently", "go silent", "back to silence", "work in silence", "don't write anything until I write", "nothing but tool calls", "stay quiet and keep going", or any request to keep working without writing to the conversation.
